# Icon Design Principles

Effective icon design relies on shape, contrast, and metaphor to communicate clearly to the user.

## 1. simplicity

Icons should use the minimum number of shapes and minimum complexity of shapes to convey an idea.

For example a square is more complex than a circle, because it naturally has 4 corner areas for your eye to rest on, wheras the circle is simple as a whole.


## 2. clarity

Often times an icon will represent an object that exists in the physical world. When this is the case, it's important that the outline of the shape reads consistently in order to make the object unambiguously recognizable and distinguished from other similar shapes.

Especially if there are other similar icons within the icon set, you must use the most salient attributes of that object in order to make it clear.
