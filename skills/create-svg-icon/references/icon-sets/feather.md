# Feather Icons

**Style**: Stroke, minimal, geometric
**Base size**: 24×24
**Stroke**: 2px, round linecap/join
**License**: MIT
**Browse**: https://feathericons.com
**Source SVGs**: https://github.com/feathericons/feather/tree/master/icons

## React usage

```tsx
import { Search } from 'react-feather'
```

## Finding path data

Browse feathericons.com and download SVG, or find the icon by name in the GitHub `icons/` directory.
