# Tabler Icons

**Style**: Stroke, 2px, very large set
**Base size**: 24×24
**Icon count**: 5000+
**License**: MIT
**Browse**: https://tabler.io/icons
**Source SVGs**: https://github.com/tabler/tabler-icons/tree/master/icons

## React usage

```tsx
import { IconSearch } from '@tabler/icons-react'

<IconSearch size={20} stroke={1.5} />
```

## Finding path data

Search at tabler.io/icons, click the icon, copy SVG. GitHub has icons in `icons/outline/` and `icons/filled/`.
