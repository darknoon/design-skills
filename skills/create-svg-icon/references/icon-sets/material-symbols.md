# Material Symbols (Google)

**Style**: Rounded, sharp, or outlined variants; variable weight via font axes
**Base size**: 24×24
**License**: Apache 2.0
**Browse**: https://fonts.google.com/icons
**npm**: `@mui/icons-material` (Material UI), `material-symbols` (standalone)

## React usage (Material UI)

```tsx
import SearchIcon from '@mui/icons-material/Search'

<SearchIcon sx={{ fontSize: 20 }} />
```

## React usage (standalone)

```tsx
// Use as icon font via CSS class, or import SVG directly
import { Search } from 'material-symbols'
```

## Finding path data

Browse fonts.google.com/icons, select style (Outlined / Rounded / Sharp), click the icon, download SVG.
