# Heroicons

**Style**: Clean geometric stroke (outline) and solid (fill) variants
**Base size**: 24×24 and 20×20
**Stroke**: 1.5px, round linecap/join
**License**: MIT
**Browse**: https://heroicons.com
**Source SVGs**: https://github.com/tailwindlabs/heroicons/tree/master/src/24/outline

## React usage

```tsx
import { MagnifyingGlassIcon } from '@heroicons/react/24/outline'
// variants: /24/outline, /24/solid, /20/solid
```

## Finding path data

Go to heroicons.com, search the icon name, click it, and copy the SVG. Or browse the GitHub source directly for raw path data.
