# Phosphor Icons

**Style**: Stroke with 6 weight variants
**Weights**: thin, light, regular, bold, fill, duotone
**Base size**: 24×24
**License**: MIT
**Browse**: https://phosphoricons.com
**Source SVGs**: https://github.com/phosphor-icons/core/tree/main/assets

## React usage

```tsx
import { MagnifyingGlass } from '@phosphor-icons/react'

<MagnifyingGlass size={24} weight="light" />
```

## Finding path data

Browse phosphoricons.com, select the weight, copy SVG. GitHub source is organized by weight subfolder.
